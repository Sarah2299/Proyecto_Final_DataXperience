# Descripción del Proyecto
Este proyecto aplica técnicas de **Data Science** para analizar un dataset real de hardware tecnológico. El objetivo es entender cómo las especificaciones técnicas (como la memoria RAM) afectan el precio de mercado de las computadoras portátiles.

# Tecnologías Utilizadas
Lenguaje: Python
Entorno: Google Colab
Librerías: Pandas, Matplotlib, Seaborn, Scikit-learn

# Etapas del Análisis
1. Preparación de Datos: Limpieza, manejo de duplicados y transformación de variables (RAM de texto a numérico).
2. Análisis Estadístico:Cálculo de medidas de tendencia central y detección de outliers mediante Boxplots.
3. Modelado Predictivo: Implementación de una Regresión Lineal con métricas de validación (R^2 y MAE).
